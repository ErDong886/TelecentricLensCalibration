# 概述
本文档用于记录一种基于平面标定物的搭载双远心镜头的双目视觉标定数学推导过程。主要借鉴模仿的论文是Zhong Chen的2014出版的Telecentric stereo micro-vision system: Calibration method and experiments（文献1）和Hai Li的2024出版的Flexible Calibration of the Telecentric Vision  Systems Using Only Planar Calibration Target（文献2）。主要的参考书是Hartley Richard的Multiple view geometry in computer vision（文献3）。

# 1：搭载远心镜头的相机数学模型简介
远心镜头由于在透镜的焦面放置了一个孔径光阑，因此从几何光学的角度来讲在一定范围内无论物体的"远近"，像在像平面的高度都不会发生"变化"。双远心镜头的几何模型引自 Li H, Liao Z, Cai W, et al. Flexible calibration of the telecentric vision systems using only planar calibration target[J]. IEEE Transactions on Instrumentation and Measurement, 2024, 73: 1-10.

搭配远心镜头（无论双远心还是物方远心）的相机，根据仿射模型，可以将不考虑镜头畸变的线性几何成像模型写为：

$$\begin{bmatrix}u\\v\\1\end{bmatrix}=\begin{bmatrix}\alpha&\gamma&0&u_0\\0&\beta&0&v_0\\0&0&0&1\end{bmatrix}\begin{bmatrix}R_{3\times3}&T_{3\times1}\\0_{1\times3}&1\end{bmatrix}\begin{bmatrix}X_w\\Y_w\\Z_w\\1\end{bmatrix}\tag{1}$$

其中 (u, v) 为像素坐标，(X, Y) 为世界坐标系中的平面坐标，(u0, v0) 为主点坐标（大致是 CCD 像素坐标的中心，比如 2048×1536 的 CCD 大概是 (1024, 768)）。α、β、γ 和 (u0, v0) 是内参数，R 和 T 分别是外参数的旋转矩阵和平移向量。第一个矩阵称为内参矩阵 A，第二个矩阵称为外参矩阵 B。

# 2：使用平面标定板情况下的特定简化
在使用平面靶标进行标定时，通常假设世界坐标的 oxy 平面与标定板平面重合。这时标定板上的点都处在 Zw = 0 的平面上。远心镜头的投影中心位于无穷远处，主点 (u0, v0) 等于 (0, 0)。因此式(1)可以简化为：

$$\begin{bmatrix}u\\v\\1\end{bmatrix}=\begin{bmatrix}\alpha&\gamma&0\\0&\beta&0\\0&0&1\end{bmatrix}\begin{bmatrix}r_{11}&r_{12}&t_x\\r_{21}&r_{22}&t_y\\0&0&1\end{bmatrix}\begin{bmatrix}X_w\\Y_w\\1\end{bmatrix}=H\begin{bmatrix}X_w\\Y_w\\1\end{bmatrix}\tag{2}$$

其中 H 为单应性矩阵，Rs 为 B 中旋转矩阵 R 的左上 2×2 截断子矩阵，Ts 为 T 的前两行。有了数学建模，具体的标定过程可以概括为以下几个步骤。

# 3：正式标定流程

## 3.1：预备工作
首先需要对标定板的标定点进行识别，准确读取每个标定点的二维亚像素坐标。

## 3.2：求解单应性矩阵 H
根据式(3)，每张标定照片能得到标定点的像素坐标 u、v，标定板的几何尺寸已知，因此可以用直接线性变换（DLT，适用于求解超定线性方程组）求解 H 的全部元素。

$$\begin{bmatrix}u\\v\\1\end{bmatrix}=H\begin{bmatrix}X_w\\Y_w\\1\end{bmatrix}\tag{3}$$

求解之后，H 的元素记为：

$$H=\begin{bmatrix}h_{11}&h_{12}&h_{13}\\h_{21}&h_{22}&h_{23}\\h_{31}&h_{32}&h_{33}\end{bmatrix}$$

其中每个 hij 都由已知标定点求出。

## 3.3 求解内蕴矩阵 A 以及截断外参 Rs 和 Ts
由

$$H=A\begin{bmatrix}R_s&T_s\\0_{1\times2}&1\end{bmatrix}$$

可以得到

$$(A^{-1}H)^{T}(A^{-1}H)=\begin{bmatrix}R_s^{T}R_s&R_s^{T}T_s\\T_s^{T}R_s&T_s^{T}T_s+1\end{bmatrix}\tag{4}$$

完整旋转矩阵满足 R 的转置乘 R 等于单位阵。式(2)里的 Rs 只保留 R 的左上 2×2，列向量还缺 r31、r32，因此 Rs 的转置乘 Rs 一般不等于单位阵。正交性给出的约束是

$$\det(R_s^{T}R_s-I_{2\times2})=0\tag{5}$$

这个行列式条件弱于 Rs 转置乘 Rs 等于单位阵。第 3.4 节的式(10)要求把 r31、r32 补回去之后，列向量长度才是 1。把式(5)用单应矩阵元素写开，得到

$$l_1-l_2(h_{21}^{2}+h_{22}^{2})-l_3(h_{11}^{2}+h_{12}^{2})+2l_4(h_{11}h_{21}+h_{12}h_{22})=-(h_{11}h_{22}-h_{12}h_{21})^{2}\tag{6}$$

其中

$$l_1=\alpha^{2}\beta^{2},\qquad l_2=\alpha^{2}+\gamma^{2},\qquad l_3=\beta^{2},\qquad l_4=\beta\gamma$$

hij 是单应矩阵 H 的第 i 行第 j 列元素。

采集多幅照片后，用线性最小二乘求解。对第 n 幅图像，令

$$G_1^{(n)}=-((h_{21}^{(n)})^{2}+(h_{22}^{(n)})^{2}),\quad G_2^{(n)}=-((h_{11}^{(n)})^{2}+(h_{12}^{(n)})^{2}),\quad G_3^{(n)}=2(h_{11}^{(n)}h_{21}^{(n)}+h_{12}^{(n)}h_{22}^{(n)})$$

$$w^{(n)}=-(h_{11}^{(n)}h_{22}^{(n)}-h_{12}^{(n)}h_{21}^{(n)})^{2}$$

这些系数与式(6)一一对应，写成 GL = w：

$$\begin{bmatrix}1&G_1^{(1)}&G_2^{(1)}&G_3^{(1)}\\1&G_1^{(2)}&G_2^{(2)}&G_3^{(2)}\\\vdots&\vdots&\vdots&\vdots\\1&G_1^{(n)}&G_2^{(n)}&G_3^{(n)}\end{bmatrix}\begin{bmatrix}l_1\\l_2\\l_3\\l_4\end{bmatrix}=\begin{bmatrix}w^{(1)}\\w^{(2)}\\\vdots\\w^{(n)}\end{bmatrix}$$

未知量至少需要四幅不同姿态的图像才能形成可解（过定）方程组。线性最小二乘的解是

$$L=(G^{T}G)^{-1}G^{T}w\tag{7}$$

由 l1、l2、l3、l4 恢复内参：

$$\alpha=\sqrt{\frac{l_2l_3-l_4^{2}}{l_3}},\qquad\beta=\sqrt{l_3},\qquad\gamma=\frac{l_4}{\beta}\tag{8}$$

γ 由 l4 = βγ 回代，因此可以是负数。l1 = α²β² 已经进入方程组。l2 l3 − l4² 为正时即可得到 α，回代时不再对 l1 开方。

对第 i 幅图像，截断外参（含 Rs 与 Ts）记为 Ks，由

$$K_s^{(i)}=A^{-1}H^{(i)},\qquad i=1,2,3,\dots\tag{9}$$

## 3.4：求解完整旋转矩阵 R 中 r31、r32 的绝对值
r31、r32 可以由 R 的正交性求解。因为 R 的转置乘 R 等于单位阵，所以

$$r_{11}^{2}+r_{21}^{2}+r_{31}^{2}=1,\qquad r_{12}^{2}+r_{22}^{2}+r_{32}^{2}=1\tag{10}$$

直接求解容易受标定噪声影响。文献[2]用下面这组约束求 r31、r32 的一组数值，符号仍未确定：

$$r_{11}r_{12}+r_{21}r_{22}+r_{31}r_{32}=0\tag{11a}$$

$$r_{11}^{2}+r_{21}^{2}+r_{31}^{2}=r_{12}^{2}+r_{22}^{2}+r_{32}^{2}\tag{11}$$

## 3.5：使用针孔模型找到 r31、r32 的正负号，再代回仿射模型

根据文献[2]，实际远心镜头在一定程度上可以看作焦距和工作距离都很大的针孔模型。因此用针孔模型确定 r31 和 r32 的符号：

$$\operatorname{sign}(r_{31})_{\mathrm{Pinhole}}=\operatorname{sign}(r_{31})_{\mathrm{Affine}},\qquad\operatorname{sign}(r_{32})_{\mathrm{Pinhole}}=\operatorname{sign}(r_{32})_{\mathrm{Affine}}\tag{12}$$

实现上对全部图像调用 `cv2.calibrateCamera`，再把每张图的旋转向量经 Rodrigues 变换成旋转矩阵，取该矩阵第 3 行前两个元素的符号。符号为 0 时取 +1。多视图标定在针孔模型失败时中止；已知内参、只解一张图时，失败则退回 +1。

## 3.6：通过叉积求出完整的旋转矩阵 R，并用 SVD 得到 Ropt

求得带符号的 r31 和 r32 之后，rx 和 ry 已经确定，rz = rx × ry。这样得到的 R 还不是标准正交阵，再用 SVD 得到 Ropt：

$$\mathrm{SVD}(R)=USV^{T},\qquad R_{\mathrm{opt}}=UV^{T}\tag{13}$$

## 3.7：引入镜头畸变模型，使用优化算法确定全部系数的最终取值
远心相机的畸变很小，基本上可以认为只有径向畸变。按照论文[1]，径向畸变写成

$$u'=u(1+k_1r^{2}+k_2r^{4}),\qquad v'=v(1+k_1r^{2}+k_2r^{4})\tag{14}$$

其中 (u', v') 和 (u, v) 分别为畸变后和原始像素坐标，k1、k2 为畸变系数，r 为径向距离。

最后用 Levenberg-Marquardt 法最小化重投影误差：

$$\min_{A,\{R^{(i)},T_s^{(i)}\},k_1,k_2}\sum_{i=1}^{N}\sum_{j=1}^{M}\left\|\mathbf{p}_{j}^{(i)}-\mathbf{p}'(A,R^{(i)},T_s^{(i)},k_1,k_2,\mathbf{P}_{j})\right\|_{2}^{2}$$

# 5：双目重建

左右相机先各自完成第 3 节的单目标定。再取一对同步图像，用已经得到的内参分别求外参，组成

$$M=A_{3\times4}B_{4\times4}$$

A 的主点列为 0，B 中的 tz 为 0。

像素坐标先按式(14)迭代去掉径向畸变。对每一对对应点，取左右 M 的前两行，用最小二乘求解

$$\begin{bmatrix}(M_L)_{1:2,\,1:3}\\(M_R)_{1:2,\,1:3}\end{bmatrix}\begin{bmatrix}X\\Y\\Z\end{bmatrix}=\begin{bmatrix}p_L-(M_L)_{1:2,\,4}\\p_R-(M_R)_{1:2,\,4}\end{bmatrix}\tag{15}$$

下标 1:2 表示前两行，1:3 表示前三列，4 表示第 4 列。同名点还会用 `cv2.findFundamentalMat` 估计基础矩阵。基础矩阵单独保存，不参与式(15)的重建。
